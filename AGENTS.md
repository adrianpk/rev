# Repository Agent Contract

Read `.agents/ARCHITECTURE.md`, `.agents/CONVENTIONS.md` and `.agents/LINTING.md`
before changes in their concerns. Keep repository content in English.

Keep the primary checkout on `dev` for integration. Use the exact branch and
report in the approved plan for sliced delivery. Preserve unrelated work and
per-worktree build directories. Do not activate hooks or run a delivery-set gate
before its approved integration phase.
