## Evidence and interpretation

[catalog.json](catalog.json) is a fresh extraction of `Command::ALL`, its native
variants, descriptions and canonical binding targets, all `Context::defaults()`
entries, and the six `PromptAction` identities. It retains inherited entries.
The source tree identity is stored in the catalog. The extraction compiles the
candidate's actual library; it does not trust an installed editor or copy the
planning inventory. Dynamic plugin, saved-macro and AI names are not members of
the fixed public catalog and are not invented as additional frozen rows.

[reference-core.json](reference-core.json) records GNU Emacs 31.1 with Org 9.8.7
loaded under `emacs -Q --batch`. It queries stock global bindings, public
function documentation and macro-menu bindings. No personal init file is read.
[reference-modes.json](reference-modes.json) separately records the isolated
Org/Agenda, Markdown and Magit packages, revisions, active maps and contextual
observations. [mode-review.md](mode-review.md) records the mode operation owners
and deliberate differences; [mode-probe-results.json](mode-probe-results.json)
contains the owned effects and normalized proposal checks.

[probe-results.json](probe-results.json) contains asserted native results and
the separately observed reference results are retained in reference-core.json.
[audit.py](audit.py) reproduces extraction and probes. It compiles one native
library in this checkout's `target/factory-shortcut-audit/`, keyed by source
bytes, compiler and dependency selection, then links a private probe. Only
prebuilt dependency libraries are read from the supplied directory. No other
checkout's editor library or mutable build output is used as the candidate.
Temporary configuration files and editor sessions belong to the probe and are
removed on exit. No terminal subprocess, external service or personal catalog
is started or changed.

Reproduce from the repository root with `REV_AUDIT_DEPS` set to an existing
compatible Cargo dependency directory:

`python3 ops/default/report/rev-factory-shortcuts/audit.py --dependency-dir "$REV_AUDIT_DEPS"`

The default compares regenerated evidence without changing tracked files.
`--write` is the explicit extraction operation used to introduce these records.
This is a documentation audit probe, not Cargo lint, the delivery-set gate,
physical terminal acceptance or a substitute for later runtime regressions.

Each row keeps its canonical inventory identity, native effect, direct routes,
reference family, disposition and evidence family. A same-name reference is a
discovery aid, not a parity certificate. The family decisions below include
context, selection, argument, history and refusal boundaries; read them with
the row. `keep` means retain the native operation and current route, including
explicit exceptions. `named-only` means retain M-x access without inventing a
factory key. `add` is a proposal awaiting mapping acceptance, not a delivered
binding. `relocate` is also a proposed default change, retaining named and
explicit user access. `adaptation required` rejects an approximate reference
binding while retaining native controls. All mode rows now have a semantic
disposition; D01-D03 acceptance of the proposed targets is still pending.

## Family decisions and source evidence

### G01: Files, buffers, exit, search and replacement

Keep familiar file/save/exit, buffer selection, literal incremental search and
query replacement routes. `quit` canonicalizes to `save-buffers-kill-terminal`;
it is not another exit behavior. Save and departure decisions still admit
explicit consent and retain cancellation. Search previews, confirmed motion,
replacement decisions and undo groups remain separate owners. Named-only
`generate-new-buffer` and `revert-buffer` need no arbitrary key: stock global
menu entries are not ordinary terminal keyboard chords. Scope is the existing
native literal workflows, not regular-expression or Lisp evaluation parity.

Sources: [command catalog](../../../../src/command.rs),
[session dispatch](../../../../src/session.rs),
[search](../../../../src/session/search.rs),
[quit](../../../../src/session/quit.rs).
Validation cases: save/close cancellation; source-stable search cancellation;
explicit query-replace decisions; retained read-only refusal and native groups.
These existing boundaries were source-reviewed; this audit does not rerun all
filesystem/search journeys.

### G02: Motion, point, selection, kill ring and rectangles

Keep the native character/word/line/buffer, mark exchange, linear kill/yank and
rectangle families. Their source coordinates, mark shape, coalescing and
read-only admission remain authoritative. Modal word objects, screen positions,
find-character endpoints and jumps keep their modal meanings. They are not
substitutes for an unimplemented sexp or mark-paragraph operation.

P01 proposes `M-m` for `modal-line-first-text` despite its modal name. The
shared handler is usable in nonmodal editing and does not change editing state.
Eight coordinate cases across nonmodal plus all six modal states agree with
stock text-mode `back-to-indentation`: spaces, tabs, mixed indentation, blank,
empty, nonbreaking space, wide text and combining text. Native source/stamp,
history, mark, selection shape and editing state stay unchanged with explicit
count four. The count
does not turn first-text motion into a multi-line movement. This does not prove
major-mode-specific whitespace syntax or physical key delivery.

Do not bind native paragraph motion to `M-{`/`M-}` as full equivalence: it stops
at whitespace-only logical lines; the reference also depends on paragraph
variables and mode syntax. Both reach offset 4 at a plain whitespace separator;
with a reference-local `%%` paragraph rule, the reference stops at offset 4
while native motion reaches content end at 19. That rule is an explicit
reference fixture, not a claim about stock text-mode defaults.
Native matching-delimiter reaches the matching
delimiter itself; `forward-sexp` reaches past the closing delimiter. Native
joining uses the following line; reference `delete-indentation` normally uses
the previous line. Indenting one native unit is not `indent-region`; semantic
last-change replay is not the reference's general command repeat. These rows
require a separate behavior contract before any such familiar chord is added.

Sources: [navigation](../../../../src/session/navigation.rs),
[coordinate navigation](../../../../src/coordinates/navigation.rs),
[paragraphs and pairs](../../../../src/coordinates/navigation/structure.rs),
[joining and indentation](../../../../src/session/editing/lines.rs),
[region](../../../../src/session/region.rs),
[modal editing](../../../../src/session/editing.rs).
Evidence: first-text, join direction with undo/redo, paragraph and delimiter
results in probe-results.json and reference-core.json. Later runtime cases must
cover active mark/selection endpoints, rejected contexts and binding dispatch.

### G03: Panes, projects and workspaces

P02 proposes `C-x +` for the existing pane-balancing owner. The native probe
balances a nested three-pane layout with an unequal 0.3 startup split ratio,
retains the selected pane and source, and refuses balancing while a path prompt
owns input. The operation changes division allocations, not startup policy.
Keep current split/delete/cycle controls. Windmove remains named-only because
its reference defaults are opt-in and shift arrows have local editing meanings.

P04 proposes `C-x p p` for selecting and restoring a registered native Project.
The reference command can select an action to run in a project. Record this as
an analogous bounded workflow, not project-menu parity. Native persistence,
dirty-source departure, retained generation and cancellation stay with the
context transition owner. The owned probe checks source retention and refusal
without a configured catalog; it does not claim registered-project restoration
acceptance. That journey remains a runtime validation case. Workspace/catalog
management operations retain named access; no stock core family justifies new
keys for native management actions.

Sources: [windows](../../../../src/session/windows.rs),
[division balancing](../../../../src/window/division.rs),
[Project transitions](../../../../src/session/contexts/projects.rs).

### G04: Prefix arguments and history

`prefix-argument` and `universal-argument` canonicalize to the same native
entry owner; `C-u` is already present. Decimal and negative argument input,
limits, command-specific admission and cancellation remain native. P03 proposes
`C-M-_` for `undo-redo` in nonmodal, Insert and Replace only. Preserve nonmodal
`C-r` backward search and the existing modal Normal/Visual history controls.
The join probe verifies one native edit followed by undo and redo; it does not
certify every count/group or read-only history case. Normalized `C-?` equals
Backspace and must not become a purported distinct redo shortcut. No new
unbinding sentinel or stored configuration format is introduced.

### G05: Focused prompts and completion

Keep source-bound completion and prompt-stage ownership. `completion-at-point`
and stock `complete-symbol` belong to the familiar `C-M-i`/Meta-Tab completion
family; that is not a claim that candidate sources/ranking are identical.
Prompt actions are configurable but are not M-x commands. RET, TAB, navigation
and history have stage-specific effects, so their six rows below are separate
from the 707-command catalog. A multi-chord mapping cannot consume a pending
decision's answer as its suffix. Keep `C-g` cancellation and modal `M-x`
recovery protected. The probe rejects protected overrides and verifies alias
normalization, not arbitrary prompt journeys or selector hint acceptance.

### G06: Tree and bookmarks

Keep the established `C-x t` native tree namespace, including its width and
horizontal panning controls. The stock reference assigns this prefix to tabs;
the tree is an explicit product exception and does not become Dired or a tab
UI. Native file create/delete/rename ownership and confirmation remain intact.
Bookmark listing uses `list-bookmarks` where the reference uses
`bookmark-bmenu-list`; preserve that existing access and the bookmark
projection's flagged-deletion and source-return semantics. Native automatic
file persistence, markers and next/previous traversal remain their own bounded
features. Menu-only reference entries do not justify extra terminal chords.

### G07: Macro recording, definitions and ring menu

Keep F3/F4, recording/end/call, ring/counter/query and definition-edit families.
The native library stores checked declarative operations; it does not evaluate
reference Lisp or provide arbitrary registers. Its finite execution budget,
state admission, undo grouping and stale-target checks remain intentional
differences. `abort-recursive-edit` is indirectly reachable through `C-]` during
native macro manual editing, even though it has no raw factory entry. `C-g`
also aborts that pause. The stock recursive-edit abort is broader than this
native pause; no additional global mapping is proposed.

The macro menu directly routes position, transpose, counter, format, definition,
column editing, mark/unmark, flag/delete, copy, refresh, help and quit. Reference
menu key lookups are retained separately from global bindings. Native bulk copy
and delete require their own consent; menu rows carry stable definition and
revision identities. The definition editor uses `C-c C-c`, `C-c C-q` and
`C-c C-r`; its TOML publication is not reference macro-syntax parity. Keep
source-safe cancellation and the distinction between ring, named and saved
snapshots. Named macro save/load/delete/export and listing need no arbitrary
factory additions.

### G08: Terminal, shell and auxiliary native operations

Keep terminal lifecycle/copy/send controls, shell execution, AI, plugin, LSP,
gutter and presentation operations within their existing owners. Stock core
bindings do not establish a compatible package convention for them. Explicit
terminal send actions target child input, while editor commands operate on
native source; apparent readline-like names do not make these interchangeable.
Shell region insertion/filtering and native async consent/cancellation are
bounded workflows. Named-only management controls stay named-only; supported
existing direct routes stay intact. This audit starts no programs for these
families and makes no transport, process-lifecycle or package parity claim.

Sources: [terminal commands](../../../../src/command/terminal.rs),
[terminal session](../../../../src/session/terminals.rs),
[auxiliary catalog](../../../../src/command.rs).

### G09: Profiles and protected recovery

All six modal states have separate factories and overrides. `keys.editor`
overrides do not flow into modal state maps. Prospective P01/P02/P04 additions
were admitted separately in each modal owner; P03 was added only to the editor,
Insert and Replace probe maps. The probe retains Normal `C-o` jump-backward,
Insert `C-o` one Normal command, nonmodal `C-r` search and Normal `C-r` redo.
Common factory inheritance does not imply shared user override ownership.
Mode overlays and actual hint/physical-input acceptance remain later checks.

Sources: [modal map ownership](../../../../src/input/keymap/vim.rs),
[context catalog](../../../../src/input/keymap.rs),
