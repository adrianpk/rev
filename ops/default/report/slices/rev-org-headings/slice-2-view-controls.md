## Purpose

Control native Org source/pretty heading presentation independently per view
without changing canonical text, coordinates or immutable startup preferences.

## Delivered Behavior

- `org-pretty-headings-mode` toggles the active native Org view and records an
  explicit pretty override, including a choice equal to startup. The reset
  command `org-reset-heading-presentation` clears that override.
- M-x, modal colon and admitted user keymaps share the two compiled handlers.
  Both commands admit read-only Org results and reject non-Org views. Neither
  has a factory shortcut, changes the editing profile or writes TOML.
- Splits inherit startup policy and explicit provenance; subsequent choices
  remain independent. Buffer rebind, local edits, undo and checked disk reload
  preserve each view's choice. Plain buffers ignore the retained preference.
- Prefix cells, cursor and pointer targets, source/Visual selection, literal
  contexts, Unicode wrapping and ordinary Org structural behavior retain their
  canonical meanings. Copy obtains stars; presentation creates no history.
- Read-only native generated-result views admit source/pretty/reset. Applying
  or discarding their original checked payload returns to source while retaining
  the live heading choice; display escapes never become accepted generated text.

## Implementation Notes

Only one optional Boolean is mutable per view. Marker arrays and the other
startup leaves remain in the bounded immutable policy. Splits copy override
metadata by value and share the admitted policy; ordinary rebind preserves both.
The existing frame projector reads the effective pretty value without changing
its source/wrap/hit owners or retaining another decoration index.

Native observation demand uses visible views' effective policies. A reproduced
canceled-attempt case left the same revision without heading evidence. Explicit
pretty re-enablement or reset to pretty now requests another observation only
when current structure is unavailable. The existing worker still owns source
admission, finite bounds, cancellation, retirement and publication; no retry
clock or additional worker is introduced.

The native result acceptance test reproduced a lost override when restoring a
captured source view. Apply/discard now carry only the current heading policy
into that restored view. Existing payload/revision/readonly admission, original
generated bytes, source anchors, undo and result consumption stay authoritative.
Controlled typed generation fixtures exercise this boundary without a provider
or model process.
