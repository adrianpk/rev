## Purpose

Exercise the integrated editor capabilities together through native input,
rendered terminal cells and canonical filesystem/history outcomes.

## Delivered Behavior

Two named combined journeys run with RGB and NO_COLOR. Each starts without a
configuration entry, verifies the complete generated bytes and passive other XDG
roots, then exercises ordered arrows, goto-line, nested shared panes and a tree,
independent absolute/relative gutters and pane-local left/right status groups.
Pointer clicks include their release before independent wheel input. Dragged
Unicode/CRLF text uses the canonical region, copy/kill and one undo/redo. Whole
marked conversion in both directions retains all displayed columns and exact
BOM, Unicode, CRLF and final-newline bytes through explicit save/history paths.
Malformed/canceled goto-line and rejected file ingress preserve the entire
retained workspace. Search highlights align with absolute labels; rectangle
copy/yank into another buffer verifies expanded-tab bytes and separate history.
A real drag-edge deadline fires before resize retires capture. Late reports after
resize or C-g cannot mutate the retained frame/point, and idle remains event-driven.
Narrow status omits the mode first and restores each pane's complete groups when
space returns. Native mouse-mode disable/enable preserves ignored-input state
and the reporting pair's terminal cleanup order.

## Implementation Notes

The existing configuration/UI runner, PTY lifetime, frame decoder and filesystem
snapshot owner are reused. Source and configuration directories are separate
within each owned fixture. All eight prior cases remain in the runner.
A primary click includes release before wheel input because a live selection
capture intentionally owns pointer input until release/cancellation.
