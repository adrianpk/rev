# Org task guides

Use these procedures for a specific task after learning ordinary file and
save controls. For an introduction, start with the [Org guide](../../tutorials/user-guide/org/index.md).

- [Capture a task](../capture-task.md): add a task to a chosen inbox.
- [Extract code from Org](../extract-org-code.md): tangle source blocks into code files.
- [Export an Org document](../export-org.md): write HTML or Markdown to an explicit destination.

The [Org reference](../../reference/org/index.md) covers every delivered
command, key, startup setting and feature. [Org support](../../explanation/org-support.md)
explains the relationship between source documents, views and optional tools.
