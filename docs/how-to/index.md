# How-to guides

Use these guides when you know what you want to do. For a first editing
session, start with the [User Guide](../tutorials/user-guide/index.md).

## Everyday editing

- [Install rev](install-rev.md): install the editor from a source checkout.
- [Edit and save files](edit-files.md): open a file, save it or choose another filename.
- [Save and revisit named locations](use-bookmarks.md): keep bookmarks across sessions, manage names and control their markers.
- [Configure indentation by language](language-indentation.md): give Rust files their own indentation settings.
- [Use completion](use-completion.md): choose names near the cursor and configure automatic requests.
- [Use a language server](use-language-server.md): register or acquire a server, select sources and manage updates, cancellation and removal.
- [Register grammar assets](register-grammar.md): admit precompiled syntax and completion queries for an explicit language.
- [Recover edits](recover-edits.md): resolve file, save and tree errors while retaining live text.

- [Use integrated terminals](use-integrated-terminal.md): open shells, move live tools, copy output and close owned jobs.
- [Run a shell command or text filter](run-shell-command.md): process selected unsaved text, insert output and inspect failures.

## Git

- [Review and commit changes](review-and-commit.md): exact paths, hunks, groups, discard, normal commits, amend and fixup.
- [Integrate Git changes](integrate-git-changes.md): explicit fetch, reviewed push, integration, ordered revisions and conflict resolution.

## Org mode

The [Org task guides](org/index.md) group capture, code extraction and export.
For a guided introduction, use the [Org mode guide](../tutorials/user-guide/org/index.md).

## Repository validation

- [Run terminal journeys](terminal-journeys.md): exercise real-editor PTY workflows and inspect their evidence.
