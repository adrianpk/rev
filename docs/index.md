# Documentation

These pages cover rev 0.6.0.

Start with the [User Guide](tutorials/user-guide/index.md) to open, edit and save
your first file, then learn buffers, search, bookmarks, file browsing, preferences
completion, optional modal editing, file reload, optional Pi editing, local shell text filters and integrated terminals.

- [Tutorials](tutorials/index.md): learn through the ordered User Guide.
- [How-to guides](how-to/index.md): install rev or complete a specific task.
- [Reference](reference/index.md): look up commands, keys, configuration and exact behavior.
- [Explanation](explanation/index.md): understand the editor's behavior and design.

## Git

The [Git learning path](tutorials/user-guide/git/index.md) covers saved changes,
selected commits and history independently. Use the [Git reference](reference/git.md)
for exact controls and limits, or [Git ownership](explanation/git-ownership.md)
for source, repository and process boundaries.

## Org mode

The [Org mode guide](tutorials/user-guide/org/index.md) has an independent
path for outlines, planning and tables, with links to Org procedures and
references. Use it when you want those features.
