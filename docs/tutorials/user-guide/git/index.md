# Git

Review saved changes, choose what enters the index and make a commit inside
rev. This independent User Guide path needs an installed Git executable and
ordinary file/save controls; it does not require Org or a terminal buffer.
The examples use a disposable local repository and never contact a remote.

## Get started

1. [Inspect Saved Changes](../17-git-status.md): compare a saved file with its index and return to editing.
2. [Stage and Commit](../18-git-index-and-commit.md): stage a change, compose a message and inspect the resulting commit.
3. [Explore Repository History](../19-git-history-and-remotes.md): inspect a revision, create a local tag and distinguish fetch from integration.

Start with [Edit Your First File](../01-first-file.md) if opening, editing or
saving a file is new. The Git keys work in both startup profiles. M-x and
modal colon expose the same `git-` commands; editable composers keep ordinary
text input.
