# Edit Markdown

Use this independent path to write a local Markdown note, compare pretty and
source presentation, continue a list and edit a GFM table. It works offline in
either interaction profile and does not depend on Org mode.

1. [Edit Markdown](../23-markdown.md): save source, continue and move list items,
   then create, align and change tables.

Return to the [User Guide](../index.md) for everyday editing. Use the
[Markdown reference](../../../reference/markdown.md) for exact controls and limits.
