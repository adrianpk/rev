# Org mode

Use Org for notes, outlines, tasks and tables. It comes built into rev and has
its own learning path here. The [User Guide](../index.md) covers everyday
editing independently.

These chapters use the ordinary file, save and M-x controls. If those are new,
start with [Edit Your First File](../01-first-file.md) and
[Search and Run Commands](../04-search-and-commands.md).

## Get started

1. [Write Org Notes](../06-org-notes.md): create headings and fold an outline.
2. [Plan Tasks](../07-org-tasks-and-agenda.md): complete a task, schedule another and find it in the agenda.
3. [Calculate a Table](../08-org-tables.md): align cells and recalculate a numeric column.

Each chapter creates a small document. You do not need a prepared project or
configuration to follow these examples.

## Specific tasks

- [Capture a task](../../../how-to/capture-task.md) while editing another file.
- [Extract code from Org](../../../how-to/extract-org-code.md) into a source file.
- [Export an Org document](../../../how-to/export-org.md) as HTML or Markdown.

These procedures stay in the how-to section; they are not required steps in
the learning path above.
