# Tutorials

The [User Guide](user-guide/index.md) is the starting point for learning rev.
Its chapters cover a first saved file, editing, buffers and panes, search,
file browsing, Projects and Workspaces, preferences, native completion and optional modal editing.

For a specific task, use the [how-to guides](../how-to/index.md). Exact controls
and settings belong in the [reference](../reference/index.md).

## Git

The independent [Git path](user-guide/git/index.md) starts with a local repository,
then reviews saved changes, selected commits and history.

## Markdown

The [Markdown path](user-guide/markdown/index.md) teaches offline native presentation,
list continuation and GFM tables without depending on Org.

## Org mode

The [Org mode guide](user-guide/org/index.md) starts directly with an Org file
and continues through outlines, tasks, agendas and tables. It is separate from
the everyday editor learning path.

## Experimental plugins

- [Try an Experimental Plugin](user-guide/plugins/index.md): a separate optional editor lesson for a reviewed local package.
- [Write Your First Experimental Plugin](write-plugin.md): build a Rust SDK command and verify its native completion feedback.
